# Portfolio

Cinematic scroll-driven portfolio built with Three.js, vanilla JS, HTML and CSS, with [Lenis](https://github.com/darkroomengineering/lenis) for smooth wheel and trackpad scrolling. Scroll to drive a 1940 Ford coupe up the hill, into space and back down.

- **Live:** https://worstpoetgit.github.io/portfolio/
- **Mirror:** https://portafolio.fridayai.win (self-hosted on a Raspberry Pi)
- **Classic stacked-card version:** [`/classic/`](https://worstpoetgit.github.io/portfolio/classic/)

No build step. Open `index.html` through any static server.
